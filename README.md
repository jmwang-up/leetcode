## 使用方式

- 点击上方表格中的分类名，进入对应目录查看该算法下的全部练习文件。
- 每个子目录内的 `README.md` 列出了该目录下所有 `.py` 文件及其题目说明，点击文件名可直接跳转查看代码。

## 命名约定

- `l_*.py`：LeetCode 题解
- `lc_*.py`：LeetCode 题解
- `h_*.py` / `h_hw_*.py` / `h100.py`：练习 / 作业题解
- `chaojubian*.py`：超解法 / 复盘练习
- `demo*.py` / `binary_turn.py`：演示与脚本
